## CloudShell から EC2 インスタンスに SSH 接続する

chmod 400 aws-hands-on-book.pem 

ssh -i aws-hands-on-book.pem ec2-user@(EC2 インスタンスのパブリック IPv4 アドレス)

curl http://checkip.amazonaws.com/

## httpd をインストールし、EC2 インスタンスを Web サーバーにする

sudo dnf update -y

sudo dnf install -y httpd

sudo systemctl start httpd

sudo systemctl enable httpd

sudo dnf install -y php8.5

sudo vim /etc/httpd/conf/httpd.conf

httpd -t

sudo systemctl restart httpd

sudo dnf install -y git

git clone https://github.com/ketancho/aws-hands-on-book-resources.git

sudo cp -r aws-hands-on-book-resources/assets/Day04/* /var/www/html/
